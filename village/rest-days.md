# Rest days

The owner's days off for the village: no topic, no script, no video chat. One date per line
as `- YYYY-MM-DD: reason`. `node tools/rotation.js` prints "REST DAY" for these dates and
`village-day` stops after a short log line. Add a date when the owner says "no need to work
tomorrow" (Hawaii date!).
